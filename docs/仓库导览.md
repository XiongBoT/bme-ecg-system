## 文件放在哪里

| 文件类型 | 归属 |
| --- | --- |
| 跨模块接口、协作与导览 | 根 `docs/` |
| 模块使用及技术说明 | 模块 `docs/`；硬件沿用 `Doc/` |
| 早期设计、旧方案和阶段图 | 模块 `docs/archive/`，由索引标注阶段 |
| 软件测试 | 对应模块 `tests/` |
| 构建、部署与检查脚本 | 现有模块 `tools/`、`deploy/` 或根 `tools/` |
| 安装包 | GitHub Releases；生成包不加入 Git |
| 真实记录、账号数据库、凭据、运行环境 | 本地或另行授权的存储位置，不加入 Git |

`README.md` 负责导航，现行步骤在模块 `docs/`，`README.txt` 是自动生成的离线版本；不要独立修改两份内容。新增重要入口时更新所属目录 README 和文档中心。源码、启动脚本、Keil 工程及模型依赖沿用现有路径；跨模块改动先核对 [接口约定](接口约定.md)。
