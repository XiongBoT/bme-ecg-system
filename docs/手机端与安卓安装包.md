## 账号管理与版本更新

使用者继续用账号密码登录，微信登录暂不实现。新版管理员功能包括搜索与筛选、创建校验、登录概况、重置密码、停用/恢复及撤销登录；操作说明见[管理员账号管理](../心电云端平台/docs/使用说明.md#管理员账号管理待部署)。普通账号只能查看自己的记录，公开下载不会开放其他人的心电数据。

手机浏览器/PWA 和 Windows 网页入口随服务器页面更新；Android 的页面打包在 APK 内，需服务器先支持新接口，再构建发布新版 APK。更新 APK 时沿用原签名、提高版本号并检查覆盖安装；仅刷新现有 APK 不会获得新的内置管理界面。具体交付状态见[版本与交付状态](版本与交付状态.md)。

### 2026-11-24 日常使用流程（1.0.2，本地构建）

在分支 `feat/mobile-usability-20261124` 延续本地 1.0.1 界面改动，增加以下操作流程：

| 用户任务 | 当前源码中的入口与行为 |
| --- | --- |
| 第一次使用 | “记录”顶部三步引导；无记录且未筛选时自动展开，明确测量在设备端进行 |
| 找到记录 | “今天、近七天”按设备记录的采集日期筛选；列表按上传登记时间由新到旧分组，“最近一条”返回第一页后打开当前筛选范围的首条 |
| 查看设备 | “设备”页显示已授权设备、状态和上报时间；可直接筛选该设备记录，不显示其他用户当前采集信息 |
| 读懂结果 | 点记录进入详情，先看摘要、采集完整性和两个独立分析状态；专业术语可展开，采样点数及上传细节归入“详细信息” |
| 更新数据 | 保留刷新按钮并支持记录页顶部下拉；显示成功读取时间，读取失败明确标记上次数据；不会把“上传完成”当成“采集完整” |
| 导出报告 | “预览报告”生成当前已读取数据的快照，标明终端/云端来源、当前窗口波形范围、设备时钟提示和生成时间；安卓打开系统打印，可选择保存 PDF；浏览器使用打印入口 |
| 找到 CSV | 沿用原下载校验和系统保存器；保存成功后提供“打开文件”，无关联应用时说明已保存、可通过文件管理器查看 |
| 登录与求助 | 密码显示/隐藏；“我的”显示版本与使用帮助；忘记密码需联系创建账号的项目管理员，不包含预设联系方式 |

报告预览不自动缓存、上传或分享。切换账号或记录后快照失效；安卓打印使用禁用脚本和网络的独立 WebView，等待页面加载后提交系统打印。报告包含的波形仅为当前已读取窗口，完整原始数据仍通过 CSV 导出。

### 手机界面与合并

720px 及以下使用“记录、结果、账号”底部导航，记录纵向排列、搜索筛选可收起，结果优先显示测量总结，并提供波形和分析定位。记录读取失败可重试；日期范围错误不发请求。账号退出和切换清空移动导航、旧结果及错误状态。非结果页减少详情轮询，相同列表保留原按钮和焦点。

合并时保留电脑端窗口/幅度调整、心搏筛选、连接恢复和下载功能。分开手机/电脑导航元素标识，共用可折叠筛选面板；手机离开结果页时退出波形专注，防止记录列表继续隐藏。APK 的明确资源清单同步包含合并后的电脑与连接脚本，避免升级后缺少资源。
