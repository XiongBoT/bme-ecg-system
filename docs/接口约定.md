# 接口约定与联调

基线日期：2026-11-23。这里提供共同索引；具体实现和测试仍是核对依据。修改接口时应在同一 PR 中列出发送方、接收方、兼容策略和测试。

## STM32 → 树莓派

| 项目 | 当前约定 |
| --- | --- |
| 串口 | USART1，115200，8N1，无流控 |
| 采样率 | 360 Hz |
| 每点格式 | `AA 55 MODE SEQ DATA_H DATA_L SUM`，7 字节 |
| MODE | 0：真实 ADC；1：板端模拟 |
| SEQ | 8 位，0～255 循环 |
| 数值 | 高字节在前；0～4095 有效，0xFFFF 无效 |
| 校验 | `(MODE + SEQ + DATA_H + DATA_L) & 0xFF` |
| 块 | 36 点，252 字节；接收必须支持任意拆分和合并 |

说明：`树莓派心电终端/docs/STM32串口对接说明.txt`、`硬件/STM32心电采集/Doc/2026-10-27_七字节串口协议.txt`。

验证：终端 `tests/test_protocol.py`、`tests/test_serial_connection.py`。8 位序号和累加校验不保证检测所有丢失或损坏。

## 采集 → 算法

原始 ADC、来源和质量标记保留；滤波、心率和模型结果作为派生结果。修改量纲、采样率、R 峰/窗口定义或模型标签时，需要同时更新端侧实现、云端适配及验证数据。

当前主模型位于终端 `cardioedge/`，云端副本位于 `cloud_model/vendor/`，来源与摘要见 `cloud_model/SOURCE.json`。旧 `models/` 用于历史原型和回归测试，不应与当前模型混用。同步云端副本时记录新旧摘要。

离线算法验证入口为 `心电云端平台/research/evaluate_ecg.py`；`requirements-research.txt` 只用于读取公开标注，不加入服务器运行依赖。输入为360Hz MIT-BIH通道0，固定200 counts/mV映射到ADC中点2048；不改变实采协议或现有模型输入。默认输出到被Git排除的 `outputs/qrs-hrv-evaluation/`；已审查的公开数据报告另存仓库 `docs/algorithm-validation/`。

R点和RR统计使用检测器的完整输出；不能用稀疏分类心搏替代。NN必须同时具有明确窦性节律和正常心搏标记，跨原始无效段、节律变化或被排除间期不计算连续差。未确认窦性时只称RR变异性，不把模型N类当作NN。报告的处理速度不包含模型分类、网络或排队，不能作为树莓派或公网容量结论。

## 树莓派 → 云端

原始块使用 ECGRAW01 v1/v2；头和行结构见两端的 `protocol.py`（终端上传部分为 `cloud/protocol.py`）。保持内容哈希校验、分块重传幂等和会话完成清单一致。

云端身份、设备授权和记录所有权由服务端校验。设备身份不得仅由请求正文中的编号决定；重传不得改变既有记录归属。

## 云端 → 网页

路由以 `心电云端平台/server.py`、`device_routes.py` 与 `tests/` 为准。现有接口覆盖会话列表、记录信息、设备状态和后台分析任务。多设备与手机功能的完成及部署状态以该模块的 `docs/云端工作台迭代.md` 为准，不将计划清单等同已上线功能。

对任何接口变更，在 PR 中记录：请求字段、响应字段、错误状态、旧客户端行为及迁移步骤。网页换账号、换设备或换记录时，旧请求结果不能覆盖当前选择。

### 统一管理后台（2026-11-25，待部署）

页面为 `/admin`、`/admin/accounts`、原有 `/devices` 和 `/database`。HTML 是不含业务数据的静态外壳，以下 API 仅管理员可用；未登录 401，普通账号或设备凭据 403，写操作继续要求 Cookie 与 CSRF。普通用户与管理员的个人记录读取范围不变。所有响应沿用 `Cache-Control: no-store` 和当前用户标识，网页换号或失权后清除详情及迟到结果。

| 接口 | 输入与返回 |
| --- | --- |
| `GET /api/admin/console/overview` | 返回读取时间 `measured_at`、北京时间 `day`、设备/账号/记录计数、每记录每类型最近分析任务状态与最多 8 项失败元信息、维护任务及最近成功备份、磁盘空间；不返回原始波形、模型结果或凭据 |
| `GET /api/admin/console/accounts` | `q` 最长 32，`status=all/active/disabled`，`role=all/user/admin`，`limit=1..100`，`offset=0..1000000`；返回 `accounts,total,limit,offset`，列表含有效记录和关联设备数 |
| `GET /api/admin/console/accounts/{uid}` | 返回单个 `account`；不存在 404。关联设备数包含停用设备和旧版共享设备，非实时在线数 |
| `GET /api/admin/console/devices` | `q` 最长 100，`connection=all/online/offline/unknown/disabled`，可选 `account_id` 与 `grant=all/granted/ungranted`，相同分页边界；返回 `devices,total,limit,offset,account` |
| `GET /api/admin/console/devices/{did}` | 返回 `device` 和最多 5 条最近登记记录元信息；包含授权名单、最近心跳及上传活动，不返回心跳中的信号内容；不存在 404 |
| `PUT /api/admin/console/accounts/{uid}/devices/{did}` | 请求仅含严格布尔 `granted`，返回设备/账号编号及授权状态。事务内重查管理员、账号、设备；不替换其他账号授权。不存在 404，旧版共享或向停用对象新增授权 409；重复同状态幂等，仅实际变化追加 `grant/revoke_grant` 管理操作记录 |

设备 `connection` 依据启用配置及 35 秒心跳边界；旧心跳的 `state` 固定 `unknown`，不能显示仍在采集。总览计数排除回收站，“今日上传登记”使用云端 `created_at` 的北京时间自然日。`GET /api/admin/database/records` 新增 `registered_day=YYYY-MM-DD`，独立于原有采集时间过滤，非法日期或 `9999-12-31` 返回 422。

完整设备编辑继续使用 `PATCH /api/admin/devices/{did}`。新增可选 `expected_user_ids` 与严格布尔 `expected_legacy_shared`，与 `user_ids` 同传时在一个写事务内核对；不一致返回 409，名称和授权都不保存。当前网页在名单未变时省略 `user_ids`，允许保留停用账号的既有授权，但不能新加停用账号。旧客户端不带预期值仍沿用原有替换语义；部署后应刷新旧管理页再编辑，避免旧页面全量保存。单账号授权接口不改变记录归属。

不增加数据库表或强制迁移；旧 API 仍可用，回退不会清除授权与管理记录。云端包新增管理模块及公共/总览/账号网页资源；Android 管理导航改在系统浏览器打开固定可信站点，保留筛选参数但不传递登录凭据。PWA 对管理导航仅提供匿名离线提示，API、管理 HTML 和记录不进入缓存。本轮没有部署或发布 APK。

### 管理员账号管理（2026-11-24，待部署）

`GET /api/admin/users` 保留 `users` 数组及每项 `id/username/is_admin/active`，新增 `created_at`、`last_login_at`（Unix 秒或 null）与 `active_sessions`（当前未过期且账号启用的浏览器登录数）。只有管理员可读；登录和 `/api/auth/me`、设备接收人列表不附带这些信息。有效登录不等于实时在线，也不等于物理设备数。旧账号未保存的时间为 null，不用迁移时间冒充历史创建或登录时间；失败登录不更新最近成功登录。

`POST /api/admin/users/{user_id}/revoke-sessions` 无必需请求体，返回 `{"revoked_sessions":整数}`，表示操作时撤销的未过期登录数；同时清理该账号过期登录。只允许管理员操作普通账号，沿用 Cookie/CSRF；未登录 401、普通用户或采集设备 403、缺少/错误 CSRF 403、用户不存在 404、目标为管理员 409。重复撤销可返回 0，不修改密码、启用状态、设备凭据/授权、记录和归属；允许用户随后重新登录，不承诺取消已获准执行中的业务请求。响应不写 Cookie，避免迟到响应覆盖其他页面的新登录。

创建账号仍用 `POST /api/admin/users`，账号去首尾空白并转小写，3–32 位 ASCII 字母/数字/横线/下划线且以字母/数字开头；密码 10–128 个字符，非法或重复账号 422。网页创建普通账号需要两次输入密码并阻止重复提交；重置密码与停用继续撤销原有登录，不删除账号或记录，管理员本身在此不可停用、重置或撤销登录。

升级自动创建独立 `user_activity` 表和会话查询索引，不改变旧用户表或原始数据。旧源码可继续运行及创建账号；回退期间不会维护新增统计，重新升级后缺失值继续显示未知，不回填虚构时间。部署前按既有流程备份数据库；手机/电脑网页随云端更新，内置网页的 Android APK 需要重新构建才包含新界面。本轮不部署、不发布安装包。

### 独立 QRS/RR 分析（2026-11-24，待部署）

网页/客户端使用 `POST /api/sessions/{id}/physiology-jobs` 提交，202 返回持久任务；`force=true` 可显式重算。`GET /api/analysis-jobs/{job_id}` 查询进度，任务新增 `kind=physiology`；旧分类任务为 `kind=model`，旧库启动时自动补齐，原分类接口不变。同一记录的两类任务独立去重，共用一个计算进程与 64 个活动任务上限。

`GET /api/sessions/{id}/physiology` 返回 `analysis_status`、`available`、算法版本/指纹、输入摘要、`summary`、`rr`、`hrv`、`performance`，尚未完成时不提供指标。`include_series=true` 另返回 `r_peaks`（原始 `sample_id` 与分析连续段 `segment_id`）和 `rr_intervals`（起止采样编号、毫秒值、是否接受、排除原因）；分析连续段编号不是上传段编号。默认汇总不携带明细序列。无可用 RR 时为 `ineligible`，未知数值为 `null`，不能按零或正常解读。

仅接收已完成清单校验、360 Hz、不超过 100 万点的记录。只分析 `serial/replay` 来源、`mode=0`、有效 ADC；跨采样编号/段内编号缺口、段变化、模式变化、中断/重同步标记、无效或质量不合格片段重置检测，不连接跨段 RR。接受区间为 280–2500 ms，标准差和相邻差指标仅称 RR 变异性；没有可信 NN 标记时 `hrv.status=unavailable`、`reason=normality_not_confirmed`、`metrics=null`，模型 N 类不构成 NN 依据。

权限沿用记录所有权，入队事务内重新验证设备凭据。未登录 401、其他账号记录/任务 404；未完成、已回收、依赖未就绪或超限 409；队列满 429。旧服务器缺少新接口时网页显示暂不可用，原分类与查看继续工作。运行依赖复用 `requirements-model.txt` 的 NumPy/SciPy，无需开启分类模型或安装 WFDB。

结果存放 `data/physiology/{session_id}/{source_digest}.json`，摘要包含原始清单、元数据、参数、算法源码及 NumPy/SciPy 版本；新版本不覆盖旧摘要，原始记录和旧分类不改写。部署回退备份应包含该缓存目录及 `cloud.sqlite`，以保留当时的完整运行状态；下述数据库管理备份仅保护数据库与原始数据，不含可重算的分析缓存，两者用途不同。迁移后的两类任务不能交给旧工作进程混合运行，更新时先停止旧服务；回退需恢复升级前数据库与源代码备份，不能只替换服务文件。验证见云端 `test_physiology_analysis.py`、`test_physiology_tasks.py` 和网页 `physiology.test.cjs`。

电脑端公开下载：`GET /downloads/ecg-workspace-windows.zip` 返回客户端附件，`GET /downloads/ecg-workspace-windows.zip.sha256` 返回校验文本；不要求登录，仅映射服务器 `deploy/dist/desktop/` 下两份固定交付物。未知名称、文件缺失或符号链接返回 404，不提供目录遍历。个人记录及分析接口仍受账号所有权保护。旧客户端入口不受影响；部署需另行复制 ZIP/校验文件，源代码包不含二进制。验证见云端 `tests/test_desktop_web.py`、`tests/test_desktop_package.py`。

### 管理员数据库管理（2026-11-24，待部署）

发送方为新增 `/database` 管理页，接收方为 `database_routes.py`。所有 `/api/admin/database` 接口均要求有效管理员浏览器登录；写操作还需现有 CSRF。未登录 401、非管理员或设备身份 403。未启用账号的旧模式不得使用管理接口。写事务内再次检查管理员有效性；记录整理与操作日志同事务提交。

| 接口 | 请求与响应 |
| --- | --- |
| `GET /api/admin/database` | 返回 `counts`（表名及行数）、`sample_count`、`uploading`、`trashed`、`database_bytes`、`disk`、`storage_scan`、`measured_at`、`backup_policy=server_only`；未扫描为 `null`，读取失败字节数为 `null`，不代表零 |
| `GET /api/admin/database/records` | `limit=25`（1–100）、`offset=0`、`q`（名称/编号，最长100）、`state=active/complete/uploading/trashed`、`owner_id`（`unassigned` 表示未分配）、`device_id`、带时区的 `started_from`/`started_before`（采集时间前闭后开）；返回 `records/total/offset/limit`，只含元信息，不含波形或备注正文 |
| `POST /api/admin/database/records/{id}/trash`、`/restore` | 无请求正文；返回 `ok/session_id/trashed_at`；不存在404，上传或分析中409。恢复与回收保留原始文件、归属及其他记录信息 |
| `POST /api/admin/database/jobs` | `{"kind":"scan"}`、`check` 或 `backup`；202 返回 `job_id/kind/status=queued`，同目录已有维护任务409；无效字段422 |
| `GET /api/admin/database/jobs` | 最近25项任务，含 `status/stage/processed/total/created/updated/result/error`；状态 `queued/running/complete/failed/interrupted`；`check` 完成不代表数据正确，还需检查 `result.ok/issue_count/issues` |
| `GET /api/admin/database/backups` | 最近100项成功备份的文件名、字节数、SHA256、记录/块数与创建时间；不返回路径、URL或文件内容。代表创建时结果，不代替后续磁盘检查 |
| `GET /api/admin/database/activity` | `limit=50`（1–100）、`offset=0`；返回操作者编号、动作、对象、状态、时间及有限错误说明；不含凭据或波形 |

检查/扫描/备份共用独立维护进程与一个活动任务槽，离开网页继续执行；重启后运行中任务标记中断，不自动报告成功。客户端每3秒查询，退出、换号、权限失效后清空内容并忽略迟到结果。已有记录、分类、设备接口和 ECGRAW01 格式不变；旧客户端无需升级。新增两个管理表和索引，启动时兼容创建，原库记录保留。新页面需要服务端及资源同时升级；仅合并代码不产生线上入口。

备份通过 SQLite 在线快照确定清单，原始块逐块核对 SHA256、编号和点数，ZIP 回读校验后原子发布到数据目录 `backups/`。仅服务器文件权限可读取内容，无网页下载、任意 SQL、永久删除或在线覆盖恢复接口。保留至少256 MiB预估空间，最多100000个归档条目，数据库快照限120秒；空间预检不能保证其他进程不会继续占用磁盘，失败时任务明确报错。派生模型/QRS缓存和软件配置不包含在备份中。

`tools/restore_database.py` 仅写不存在的新目录，验证清单、文件摘要、路径与数据库/原始块一致性。恢复保留账号和记录，撤销旧浏览器会话及设备密钥；分析任务标记需重新执行，维护任务标记中断，结果缓存需重建。命令不替换正式服务。恢复切换、凭据重发及完整部署回退另行安排。验证见云端 `test_database_management.py`、`test_database_backup.py` 和网页 `database_manager.test.cjs`。

## 软件更新提醒

`GET /api/updates` 为公开只读元数据接口，响应 `Cache-Control: no-store`。仅该精确 GET 路径免账号/设备认证；原有其他 API 的登录、归属和跨站请求限制不变。检查请求不发送 Cookie、账号、记录或设备密钥，响应不创建登录会话。

返回结构：`{schema:1, web:{build_id}, windows:{version,url,notes}|null, android:{version,version_code,url,notes}|null}`。`build_id` 为服务启动时公开网页文件路径与内容的 SHA256（64 位小写十六进制），同一应用进程返回的浏览器 HTML 嵌入该值；原生 APK 的内置资源不注入网页刷新检查器。更新网页时整体部署并重启服务。

原生发布信息仅来自应用目录 `client-releases.json`：版本为三个非负整数（每段 ≤65535，无多余前导零）；Android `version_code` 为 1–2147483647 的整数。Windows 对比数字版本，Android 对比 `version_code`，相等或较旧不提示升级。链接仅允许项目 GitHub HTTPS Release 页面，Windows `desktop-v版本`，Android `android-v版本`（可附 `-preview.正整数`）。`notes` 为不超过 1000 字的纯文本；其他字段不对外返回。

清单最多 16 KiB。缺失、损坏或不支持的 schema 返回两个平台 `null`；单个平台条目异常只将该平台置空，保留网页标识。客户端须把 `null`／异常／超时视为暂不可用，不能据此判断已是最新。各端正常 TLS 校验、请求超时和响应上限保持；只能在用户操作后打开发布页或刷新。

使用与发布流程统一见[软件更新提醒](../心电云端平台/docs/更新提醒.md)。验证入口为云端 `test_client_updates.py`、网页 `update_notice.test.cjs`、Windows `desktop_update_tests.cs` 以及 Android `Update*Test.java`。
