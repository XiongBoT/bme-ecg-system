## 新功能如何到达用户端

1. 从已通过检查的提交准备服务端和网页资源，记录版本、数据备份和回退方式，再按当前任务授权部署。
2. 浏览器、PWA 和 Windows 网页入口在服务器更新后刷新；Windows 启动器自身版本单独维护。
3. Android 页面随 APK 打包：确认服务器接口已支持后，用原签名构建并发布新版 APK。仅刷新旧 APK 不会替换内置页面。
4. 分别记录安装、登录、记录查看、分析、报告／CSV 保存、后台恢复和升级结果。服务器、手机与终端各自验收。

管理员的服务器数据备份只含数据库与快照引用的原始块，不包含程序、模型和配置，不能代替完整部署回退备份。恢复只写新目录，并撤销旧会话和设备凭据，详见[备份与恢复](../心电云端平台/docs/使用说明.md#服务器上的备份与恢复)。
