## 新功能如何到达用户端

1. 选定已审核提交，记录当前版本、完整运行备份及回退方式，先核对云端接口和网页。
2. 更新树莓派终端及独立设备凭据配置，核对授权、真实串口和就绪状态，再验证手机发起测量。
3. 浏览器/PWA 与 Windows 网页入口随服务器更新；Windows 启动器自身另行构建发布。
4. Android 用原签名构建并发布新版 APK。旧包刷新不会替换随包页面。
5. 各端分别记录安装、登录、采集/保存/上传、分析、报告/CSV、后台恢复和升级结果。

详细步骤见[部署与升级](../心电云端平台/docs/部署与升级.md)。数据库管理备份不包含程序、模型、配置和派生缓存；恢复会撤销旧会话与设备密钥，并使旧测量和自动分析意图失效，须先隔离验证。

## 如何维护这页

源码合并、Release 发布、服务器/终端部署、实机验收发生变化时分别更新对应栏，并附提交、包摘要、日期及验证依据。没有新的部署证据时写“未核验”，不要由旧记录推测实时运行状态。首页和操作文档链接到本页，阶段日志保留当时事实。
