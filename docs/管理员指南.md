# 管理员指南

[文档中心](README.md) · [用户操作](../心电云端平台/docs/使用说明.md) · [交付状态](版本与交付状态.md) · [部署与升级](../心电云端平台/docs/部署与升级.md)

本页对应主分支 `b656a64`。请先核对服务器版本；登录页申请和管理新入口需要相应服务及页面。GitHub 仓库权限、服务器 SSH 账号和心电平台管理员分别管理，项目没有供所有人共用的预设登录密码。

## 从哪里进入

在[项目工作台](https://62.234.150.104/)使用平台管理员账号登录，从“我的”或账号区选择“管理后台”。直接打开页面地址仍须通过管理员身份校验。

| 入口 | 用途 |
| --- | --- |
| `/admin` | 管理概况、今日登记、待分配及管理导航 |
| `/admin/accounts` | 查找账号、创建普通账号、账号详情和设备授权 |
| `/devices` | 设备登记、凭据、授权名单和接入信息 |
| `/database` | 记录元信息、回收站、占用、完整性检查和服务器备份 |
| `/operations` | 连接、队列、磁盘、备份等运行问题 |
| 个人工作台“我的 → 账号管理” | 兼容的快捷账号窗口；待审核账号申请、历史记录分配 |
| `/tasks` | 本人记录的任务中心；不是全体用户的分析管理页 |

Android 的管理页面在固定项目站点的系统浏览器中打开，需独立登录；应用不传递密码或登录会话。

## 为新用户开通使用

1. 用户在新版登录页“申请账号”，提交账号和两次相同的密码，可附姓名或小组说明。
2. 管理员在个人工作台“我的 → 账号管理 → 待审核账号申请”核对申请并通过或拒绝。通过只创建普通账号；密码不向管理员显示，用户使用申请时的密码登录。
3. 在“管理后台 → 账号管理”查到该用户，进入“管理设备授权”，添加需要使用的采集设备。若设备未登记，先到设备管理创建，并向真实终端配置该设备专用凭据。
4. 终端联网同步接收人；用户在终端确认本次使用者，或在手机选择就绪设备发起 1／3／5 分钟测量。
5. 测量后分别核对保存、上传与分析状态，使用本人账号查看记录和报告。

管理员也可直接创建普通账号。账号为 3–32 位字母、数字、横线或下划线，以字母或数字开头；去除首尾空白后转小写。新建、申请、重置和修改密码均校验 5–128 个字符。没有账号申请入口时，先核对版本，再由管理员处理，不要反复提交。

## 账号与记录

| 操作 | 登录影响 | 数据影响 |
| --- | --- | --- |
| 重置普通账号密码 | 旧密码和已有登录失效 | 原记录、归属、设备授权保留 |
| 撤销登录 | 结束已有登录，仍可用原密码重新登录 | 原记录不变 |
| 停用账号 | 禁止登录，不再列为新测量接收人 | 原记录和既有授权保留 |
| 恢复账号 | 可用现有密码重新登录，旧会话不会恢复 | 原归属不变 |
| 分配历史记录 | 仅处理尚无归属记录 | 明确指定接收人；不能借此改动已归属记录 |

“有效登录”是尚未过期的登录凭证数，不是实时在线人数。管理员自己的账号不能在普通用户操作中被停用、重置或撤销；本人修改密码需要旧密码。首个管理员由有权限的服务器维护人员在本机使用 `manage_accounts.py` 创建，步骤见[部署与升级](../心电云端平台/docs/部署与升级.md#账号和设备初始化)。

## 接入设备怎么检查

先分清“启用配置”“近期在线”“允许远程测量”三项状态。在线表示最近 35 秒收到心跳，不证明电极质量或测量成功；未上报信息显示未知。管理员详情可读型号、系统、终端版本、串口、采样率、协议、剩余空间、登记及最近上报信息。

授权单个用户不会覆盖其他人；停用对象不能新增授权。编辑完整名单时如提示已被其他操作更新，应刷新核对，避免覆盖并行修改。旧共享设备需明确确认转为单独授权；仅改名称不改变授权模式。

设备凭据只给对应终端，不填写到手机登录页，不复制给另一台物理设备。停用设备或轮换凭据后，旧凭据不能继续写入；既有记录归属保留。

## 维护与恢复

先从运行总览定位问题，再进入数据库管理执行占用扫描、完整性检查或手动创建备份。同一时间只执行一项维护任务，退出网页后后台继续；成功备份记录只是创建时的结果，恢复能力需演练验证。

备份包含一致数据库快照与其引用的原始块，只保存在服务器。它不包含程序、模型、配置和派生分析缓存，网页不提供备份下载。回收站仍占空间，当前没有永久删除或自动清理旧备份。

恢复命令只写不存在的新目录；恢复后撤销旧登录和设备凭据、取消旧自动分析意图及活动测量请求，复核需重新确认，分析缓存需重建。按[备份恢复步骤](../心电云端平台/docs/使用说明.md#服务器上的备份与恢复)先做隔离验证，再安排切换。

## 常见入口问题

| 现象 | 处理 |
| --- | --- |
| 看不到管理入口 | 确认使用平台管理员账号，核对服务及页面版本；普通账号不会显示该入口 |
| 新账号可登录但无可用设备 | 完成设备授权，确认终端联网、空闲并在真实串口模式 |
| 管理员看得到记录数量却打不开他人波形 | 属于权限边界；由记录所属用户查看与分析 |
| 今日登记数量不等于当天测量次数 | 管理概况按北京时间云端登记日；健康趋势按设备采集开始时间 |
| 操作成功但刷新失败 | 先重新读取当前状态，不因读取失败重复创建、重置或分配 |
| 新界面返回 404 | 核对服务是否包含对应路由；仅更新 APK 或文档不会更新服务器 |

更多排查见[云端故障排查](../心电云端平台/docs/故障排查.md)。反馈只附版本、脱敏步骤和错误信息，不公开密码、凭据或真实心电记录。
