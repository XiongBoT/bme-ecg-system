# HeartLife 协作与工程准则 (AGENTS.md)

1. **完全解耦原则**：`heartlife` 是独立于 `bme-ecg-system` 的心脏健康生活与互助平台，严禁导入旧项目代码、访问旧数据库、共用会话或修改原仓库任何文件。
2. **TDD 与证据驱动**：所有任务遵循 `Red → Green → Refactor → Regression → Evidence`，在 `docs/progress.md` 记录真实执行的测试命令与退出码。
3. **隐私与医疗安全边界**：
   - 私密健康日记、习惯计划默认仅本人可见，社区审核员与内容编辑员均无权读取。
   - 本产品定位为日常健康生活记录、习惯养成、科普学习与同伴互助，不提供疾病诊断、处方用药建议、心电波形诊断或急救监护。
4. **前端体验准则**：
   - 视觉居中布局，清爽青绿与留白设计，桌面端居中导航与内容容器，移动端底部导航（375px 起无横向溢出）。
   - 界面不添加多余不必要的说明文字，保持克制、直观、可操作。
