# Windows 免安装桌面入口

稳定下载：见 [根 README 应用下载](../../../README.md#应用下载)；已发布 1.1.0 也可从 [正式云端下载](https://62.234.150.104/downloads/ecg-workspace-windows.zip)。主分支已包含 1.2 连接助手源码及本地试用记录，尚无对应 Release；公开下载仍为 1.1.0。

用途：将当前正式云端 https://62.234.150.104/ 打包为可解压运行的 Windows 启动入口，使用既有账号。无需安装 Python、Node.js；不包含离线服务、记录、凭据或尚未上线的设计稿。

实施与验收：

1. 编译无控制台 C# 启动程序，连接助手以公开首页 GET 检查连接，约 6 秒超时，允许重试和手动打开。优先 Edge、其次 Chrome 独立窗口，再回退默认浏览器。固定 HTTPS 地址，不读本地密码、不变更浏览器安全策略。
2. 仅打包启动程序、连接助手 CMD、备用 URL、说明、SHA256 清单，共 5 个文件；源码留在本目录，生成包进入 `deploy/dist/desktop/`。快捷方式仅在用户点击后创建，不覆盖已有同名文件。
3. 验证中文和带空格路径构建/解压、归档清单和摘要；覆盖连接结果、关闭取消、重复检查和多屏窗口边界。实际窗口及其他 Windows 电脑的检查结果单独记录，不用编译测试替代。

构建（Windows 开发环境，Python 3.10+ / .NET Framework 4.x 编译器）：

```powershell
python deploy/package_desktop.py
python -m unittest discover -s tests -p test_desktop_package.py -v
```

以上命令从 `心电云端平台/` 模块根目录执行。此处 Python 仅用于开发打包，不是使用者运行条件。输出 EXE 为 AnyCPU，尚未进行代码签名；不使用安装器、管理员权限、计划任务或自启动。工作台页面随服务器部署更新，启动器自身需要重新构建发布；启动地址变化也需重新构建。自动检查客户端版本仍属独立开发任务，不是当前公开包已有能力。

用户操作见 [使用说明](使用说明.txt)：完整解压后双击“心电工作台.exe”，连接成功自动打开云端，使用现有账号登录。“连接与快捷方式.cmd”以 `--connection` 打开并保留连接助手，可重试或创建桌面快捷方式。遇到启动限制可使用包内浏览器备用入口。需联网；当前包不是离线分析软件。

`Launcher.cs` 负责窗口及浏览器/快捷方式交互，`LauncherCore.cs` 负责可独立测试的连接与窗口边界逻辑。两者一并编译。本次沿用主分支已发布的电脑网页，保留记录栏、波形窗口/幅度调整、心搏筛选定位、专注查看、连接提示和下载入口。构建启动包不会自动部署网页。

部署：源码包由 `deploy/package_cloud.py` 构建；生成的桌面 ZIP 与外置校验文件需单独放在服务器 `ecg-cloud/deploy/dist/desktop/`。公开下载路由只接受两个固定文件名，不公开目录、凭据或记录。`deploy/linux/update_desktop.py` 校验更新清单，停服备份数据，切换源码，检查模型/身份保护/下载/原始数据后启动；它用于既有 ubuntu 服务，不执行初始账号创建。内部虚拟环境随旧应用保留，外部环境沿用原路径。失败时恢复代码并保留当前数据，避免覆盖新的上传。这是正式升级流程；本轮 1.2 只提供试用包，不执行部署。

1.0 源码通过 `feat/ecg-desktop-portable` 同步，已发布 1.1.0 通过 `feat/ecg-desktop-workspace-110` 合入；1.2 连接助手使用 `feat/windows-workspace`。构建生成的 ZIP/EXE、记录和凭据不进入 Git。项目进度、验收证据、交付包摘要和后续事项统一见 [云端工作台迭代](../../docs/云端工作台迭代.md) 的“Windows 免安装电脑端”小节。
