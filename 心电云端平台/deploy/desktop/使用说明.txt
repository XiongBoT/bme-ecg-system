心电工作台 · Windows 免安装版 1.2（试用）

开始使用
1. 右键压缩包，选择“全部解压”；先解压完整文件夹，再启动。
2. 双击“心电工作台.exe”。连接助手检查云端入口，成功后自动打开工作台。
   通常以独立 Edge 窗口打开；也支持 Chrome，并按当前屏幕调整窗口大小。
3. 使用已有的心电云端账号、密码登录，查看该账号有权限访问的真实记录。
4. 使用完毕在页面中退出登录，再关闭窗口；共用电脑尤其需要退出登录。

正式入口：https://62.234.150.104/
启动程序打不开时，可双击“浏览器备用入口.url”，或直接在浏览器输入上方地址。
双击“连接与快捷方式.cmd”可保留连接助手窗口，检查连接、检查更新、重试，或点击
“创建桌面快捷方式”。只有主动点击才会创建；已有同名快捷方式不会被覆盖。
更换解压位置后，请自行移除旧快捷方式，再重新创建。

更新提醒（此功能源码待发布）
- 启动时会同时检查是否有新版，每个 Windows 用户最多每 24 小时自动检查一次。
  工作台照常打开；连接助手可能短暂保留，检查完成后自动退出。
- 发现新版时，可点击“查看新版”前往项目官方 GitHub 版本页，自行查看和下载；
  也可点击“稍后”继续使用当前版本。不会自动下载、安装或强制升级。
- 要立即检查，可打开“连接与快捷方式.cmd”，点击“检查更新”。
  没联网或更新服务暂不可用时会提示“暂时无法检查”，仍可继续使用当前版本。
- 检查只读取公开版本信息，约 6 秒内结束。关闭连接助手会取消本次检查。
  本机仅保存上次检查时间，不读取账号、密码或记录。
- 当前稳定下载仍为 1.1.0；包含此功能的新包尚未发布。已安装的旧启动器
  需要先手动更换为新版包，刷新云端页面不会给旧启动器增加更新检查功能。

运行条件
- Windows 10/11，已安装并更新的 Microsoft Edge 或 Google Chrome，能够访问互联网。
- 启动程序使用 Windows 自带的 .NET Framework 4.x，不需要安装 Python、Node.js 或云端服务。
- 如电脑未提供此运行组件，使用浏览器备用入口即可。

这个版本提供什么
- 连接当前已经上线的真实心电云端服务，功能以云端页面为准。
- 沿用账号权限；没有记录时请检查所属账号、采集上传和记录分配。
- 它是云端工作台的桌面启动入口，不是离线分析软件，也不直接连接串口设备。
- 云端页面更新后，再次打开即可使用更新内容。
- 1.2 启动入口增加连接状态、约 6 秒的连接超时、重试及浏览器备用按钮。
  只检查公开首页，不读取账号、记录或设备凭据；检查失败后仍可手动打开浏览器。
- 云端电脑工作台已提供记录侧栏、波形专注查看、窗口/幅度调整及心搏筛选定位。
  点击“专注波形”可扩大波形区域，Esc 退出；数据与分析沿用现有云端。
  仅升级此启动包不会改动服务器，实际界面以当前云端为准。

账号与数据
- 压缩包不含账号密码、设备凭据、服务器密钥或任何人的心电记录。
- 需要自己的有效账号；没有账号时请联系平台管理员创建普通账号。
- 登录状态由所使用的浏览器保存；下载文件也遵循该浏览器的下载设置。
- 复制本文件夹不会复制账号、登录状态或记录。换一台电脑需要重新登录。
- 删除本文件夹不会删除云端记录。清除本机登录状态请先退出登录。

常见问题
- 页面打不开：连接助手会提示超时、网络异常或服务暂不可用。检查联网后点击
  “重新连接”，也可点击“浏览器打开”或双击备用入口；仍不可用时联系管理员。
- 证书警告：不要跳过，检查电脑时间并联系管理员检查证书续期。
- 窗口打开但需登录：这是正常账号验证，启动包不自动登录。
- 本程序为项目自编译版本，尚未进行代码签名。若 Windows 或单位策略阻止运行，
  使用浏览器备用入口；不要关闭系统防护或绕过组织策略。
- 软件展示和分析结果用于课程研究，不作为临床诊断依据。
