# 云端快速开始

[云端导航](../README.md) · [使用说明](使用说明.md) · [故障排查](故障排查.md)

## 使用现有平台

1. 从[项目首页](../../README.md#应用下载)选择网页、Windows 或 Android 下载；iPhone 使用网页，可添加到主屏幕。
2. 使用自己的心电平台账号登录。新版登录页可“申请账号”，管理员通过后使用申请时的密码登录；旧服务没有申请入口或忘记密码时联系项目管理员。GitHub 账号与平台账号分别管理。
3. 由管理员授权采集设备。在树莓派选择同一个使用者，或在手机“开始测量”选择就绪终端与 1／3／5 分钟；实际采集由终端执行，结束后保存上传。
4. 回到工作台刷新，选择记录，核对来源、采集完整性和上传状态，再查看摘要、波形及分析。需要完整数据时导出 CSV。

没有找到记录时，按[排查顺序](故障排查.md#记录与报告排查)核对账号、上传和筛选；管理员分配账号、设备及历史记录见[使用说明](使用说明.md#管理员账号管理待部署)。

账号申请、设备授权与后台地址集中见[管理员指南](../../docs/管理员指南.md)。当前源码的管理员入口为“我的 → 管理工具 → 进入管理后台”；进入“账号管理”，打开账号详情后选择“管理设备授权”，再按需查看记录信息。运行总览用于排查连接、队列及备份问题，具体步骤见[统一管理后台](使用说明.md#统一管理后台)。

### 先确认使用的是哪个版本

先查看客户端显示的版本，再对照[版本与交付状态](../../docs/版本与交付状态.md)中的源码提交、公开安装包和最近部署记录。Android 内置页面随 APK 更新；旧 1.0.0 的“记录、结果、账号”界面需手动安装新版才能更新。浏览器和 Windows 打开的网页随服务器更新，Windows 启动器版本单独维护。账号申请、固定时长测量等功能还需要配套服务和终端，不能仅凭 APK 或本地源码版本判断线上可用性。

## 本地开发

从仓库根目录按[开发环境](../../README.md#开发环境)创建 Python 环境，再进入 `心电云端平台/`：

```powershell
..\.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-test.txt
..\.venv\Scripts\python.exe run_server.py --data-dir work/local-server
```

默认仅监听 `127.0.0.1:8766`。本地数据目录与正式服务器分开；当前账号、令牌及 HTTPS 配置见[Linux 部署说明](../deploy/linux/部署说明.txt)和[公网访问说明](../deploy/linux/手机公网访问说明.txt)。不要把历史无账号演示流程作为正式登录配置。

需要在本地启用现有模型时，在启动服务的同一 PowerShell 会话中执行：

```powershell
..\.venv\Scripts\python.exe -m pip install -r requirements-model.txt
$env:ECG_MODEL = 'cardioedge'
```

然后运行上面的启动命令。仅安装权重不会启用模型；`ECG_MODEL=none` 为不启用模型。模型与输入约束见[云端模型说明](../cloud_model/README.md)。

## 检查与离线研究

从仓库根目录分别执行：

```powershell
.\.venv\Scripts\python.exe tools/run_checks.py --suite cloud
.\.venv\Scripts\python.exe tools/run_checks.py --suite web
```

QRS/RR 与 HRV 的公开数据复跑步骤集中在[研究工具](../research/README.md)，结果可直接阅读[Markdown 摘要](../../docs/algorithm-validation/结果摘要.md)。研究数据放仓库外，生成结果留本机。

## 构建与部署

首次加入云端维护，先按[云端协作者上手](云端协作者上手.md)确认腾讯云身份、项目实例和 Linux 运行账号，完成只读状态检查。

先看[部署与升级](部署与升级.md)确认云端、终端、客户端的顺序及恢复边界；服务器、Windows、Android 的构建入口见[部署导航](../deploy/README.md)。合并代码或构建安装包不自动更新服务器或设备；实际部署与待验收项按[交付状态](../../docs/版本与交付状态.md)核对，操作和历史证据见[阶段记录](云端工作台迭代.md)。
