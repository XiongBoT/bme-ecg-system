# 手机测量状态与恢复

[云端首页](../README.md) · [前端实现](../web/health.js)

打开测量窗口后，APP 检查当前账号获授权的设备。未分配设备需联系管理员；离线需检查终端电源和网络；停用需管理员启用；忙碌需等待任务结束；尚未准备好需选择真实采集串口，旧终端需要更新。

设备检查是当前状态快照，最终以服务器接受请求及终端确认结果为准。刷新设备不会重置时长。关闭重开、切换账号及后台返回时，旧设备响应不能覆盖当前窗口。

## 网络中断与重试

提交后若超时或服务器异常，结果可能尚未确认。APP 暂时锁定原设备和时长，点击“确认原测量请求”会发送相同请求编号与参数，服务器返回已有任务，避免重复采集。收到明确的参数、权限或设备拒绝后解除锁定，检查原因再重试。不能仅凭手机断网判断终端已停止。

此重试保护仅保存在当前页面内存中。退出登录、重新加载或关闭 APP 后，应先查看已有测量任务和终端状态，再决定是否开始新测量。

## 记录与报告

测量依次显示等待终端、准备采集、正在测量、正在上传记录、记录已上传。上传完成仅表示记录可供读取；打开报告会提交分析，分析成功、失败或条件不足以报告页面为准。

## 验证

在云端目录执行 `node --test tests/health*.test.cjs`。自动测试覆盖设备状态、重开窗口的迟到响应、网络重试参数、重复提交、明确拒绝和上传状态。真机仍需验证：1/3/5 分钟测量、锁屏后返回、断网恢复、电极与真实串口输入；合成 DOM 测试不替代这些验收。
