# 树莓派使用说明

[快速开始](快速开始.md) · [故障排查](故障排查.md) · [文档分类](README.md)

## 完成一次测量

1. 在待机界面接入 USB 串口；多个设备时明确选择采集端口。
2. 点击“开始采集”，核对使用者、端口、可用空间和云端状态，选择手动结束、1 分钟、3 分钟或 5 分钟。取消准备窗口不会建立记录。
3. 观察接收点数、信号质量与保存状态。“暂停显示”只冻结画面，采集和保存继续。
4. 点击“停止并保存”，或等待所选时长结束；等到保存完成后查看测量总结。
5. 在历史记录中复核、导出 CSV/ZIP 或中文 PDF；确认云端授权后可以手动上传并查看分析。

设备待机、总结和安全关机的详细行为及待验收项见[设备待机与日常使用](设备待机与日常使用.md#日常使用)。源码具备相应功能不代表板端已经升级。

## 手机发起固定时长测量

云端和终端均更新后，终端联网并保持真实串口模式的空闲状态；管理员先给本人账号分配设备。手机“开始测量”选择就绪设备与 1／3／5 分钟，确认人在设备旁、电极已准备，再发起请求。

终端领取请求后计时、保存和上传。手机断网或关闭页面不会停止已开始的测量；提前结束使用终端停止按钮。45 秒未领取的请求过期，终端重启不自动重复采集。上传失败保留本地记录，排除问题后在终端补传。

测量总结中的采样时长按实际保存点数计算；选了 3 分钟但提前停止或发生断流，不能把报告视作完整 3 分钟数据。详情与报告见[健康助手](../../docs/心电健康助手.md)。

## 来源、波形与分类

“更多 → 数据来源”可选择合成模拟或文件回放；来源标签必须保留。串口的 MODE=0 表示实采来源，MODE=1 表示板端模拟。协议有效不等于信号有效。

当前主分类模型位于 [cardioedge/](../cardioedge/README.md)，输出 N/S/V；旧 [models/](../models/README.md) 是历史原型。分类需要有效信号及前后心搏上下文，初次输出有延迟。模型分数不是诊断概率，N 类也不等于完全正常，S 类需结合波形复核。

显示电压按 ADC 与参考电压换算，不直接代表皮肤心电幅度。处理后波形用于显示对照，原始 ADC 和接收字节继续保存。具体规则见[实采预处理](实采预处理说明.txt)、[状态与信号质量](状态与信号质量说明.txt)、[分类呈现](分类呈现与复核说明.txt)。

## 记录、导出与云端

默认记录位于模块内 `data/sessions/<session_id>/`；可用 `--data-dir` 指定其他可写目录。会话包括原始块、SQLite 索引、事件与质量摘要，历史导出读取完整已提交数据。

测量总结中的有效采样比例、质量通过时间和有效 RR 心率各有不同含义；缺失统计显示未知。PDF 使用本地保存的结果，不能据此判断云端分析完成。数据管理详见[记录与设置](数据管理与设置说明.txt)。

云端支持当前 HTTPS 平台和账号/设备授权。手机使用记录所属账号登录；未分配记录由管理员处理归属。具体接入见[账号与记录归属](云端账号与记录归属.txt)，跨模块约定见[共同接口](../../docs/接口约定.md)。

## 退出与关机

先停止并等待保存完成。界面“安全关机”会确认并等待后台任务；保存失败或权限不足时不自动关机。笔记本预览不会执行树莓派关机。

开机待机配置由独立工具管理，安装、撤销与实物验收步骤见[设备说明](设备待机与日常使用.md#查看与撤销开机配置)。
