## 日常使用

1. 上电后进入待机，接入 USB 串口。自动检查只枚举设备，不打开串口、不创建记录。
2. “设备已识别”表示找到了端口；多个 USB 设备时在“更多 → 采集端口”明确选择。点击“开始采集”会先打开准备窗口，确认使用者、端口、存储和云端状态，选择手动结束、1 分钟、3 分钟或 5 分钟；取消不产生记录。离线仍可采集，空间不足或端口缺失不能开始。电极和信号质量在开始接收后判断。
3. 观察波形与质量提示；“暂停显示”只冻结画面，不停止保存。
4. 点击“停止并保存”，或等待定时时长结束，等到保存完成。定时采用单调时钟，串口断流也会到时停止；总结中的采样时长按已保存点数换算，不包含断流等待时间。保存后自动显示测量总结，历史记录也可打开总结。
5. “更多 → 安全关机”会先确认，再停止与保存，等待后台传输退出。未完成的云端任务保留，下次运行继续。保存异常或关机权限不足时不自动关机，并提示原因。
6. “退出到命令行”会等待采集与后台操作结束。在物理文字控制台启动的临时图形会话会回到命令行；从已有桌面启动则回到桌面。

模拟演示与文件回放放在“更多 → 数据来源”，来源仍在波形旁标明。新增入口不改变既有串口协议、信号处理、模型与云端地址。

测量总结显示保存状态、记录所属账号、有效采样比例、实采/模拟点数、质量通过时间、有效 RR 心率和已保存的 N/S/V 数量。有效采样比例只检查 ADC 和无效标记，不等同可分析比例；质量按逐点门控累计，心率按有效实采 RR 间期加权。没有有效数据、模拟和保存异常不显示可靠实采心率。旧记录缺少统计时显示未知。

总结可导出中文 PDF、复核波形、手动上传和查看手机访问说明。PDF 默认建议以记录编号命名，选择位置由用户决定；后台生成，不阻止下一次采集，且不覆盖原始数据。树莓派需要 `sudo apt install python3-reportlab fonts-wqy-microhei`；自定义中文字体可用 `ECG_REPORT_FONT` 指定文件。报告只反映本地已保存记录，不代表云端分析或上传成功。

手机入口沿用 `https://62.234.150.104/`。在总结中点击“上传并分析”，待上传确认后，手机使用该记录所属账号登录并刷新记录。未分配记录先由管理员指定归属；断网可稍后补传。总结和云端模型结果分别展示。以上新增功能本地已验证，需先升级云端和树莓派才会在正式设备生效。

## 启动与部署准备

笔记本使用已有项目 Python 环境运行：

```text
python app.py --standby
```

树莓派重新连接后，先比对板上文件，备份本轮将替换的文件，再传输最新 dist/ecg-cloud-workspace.tar.gz 中的运行文件；不覆盖 data 下的记录、配置与云端任务。旧 ecg-cardioedge-standby 包不包含本轮总结及手机功能；旧 install_cardioedge_release.py 固定了早期版本哈希，不用于本轮安装。

在树莓派物理屏幕上先手动验证：

```sh
sh "/home/pi2/树莓派心电终端/start-device.sh"
```

确认显示正常后，在树莓派配置开机待机：

```sh
sudo python3 "/home/pi2/树莓派心电终端/tools/configure_device_boot.py" install --user pi2
```

工具只支持 Raspberry Pi OS Lite 的文字控制台启动及 bash 用户。它在 tty1 配置普通用户自动登录，并在该用户实际使用的登录文件内加入有标记的启动段；SSH 登录与其他终端不启动界面。配置启用后，接触设备的人可进入该本地账号。工具不修改 SSH 权限、不新增 sudo 权限、不立即重启或终止采集。

应用继续使用原 start-screen.sh，保留已经验证的 HDMI 全零颜色矩阵修复。启动段只执行一次，退出界面回到命令行。start-device.sh 使用文件锁阻止同一账号重复打开设备入口。

配置与原文备份保存在 /var/lib/ecg-standby/install.json；新增启动文件为 /etc/systemd/system/getty@tty1.service.d/zz-ecg-standby.conf。安装中断时也保留恢复信息。安全关机使用现有 sudo 权限非交互调用 systemctl poweroff，权限不足时提示，绝不在窗口中索要密码。

## 查看与撤销开机配置

以下命令均在树莓派上执行；无需在笔记本运行：

```sh
sudo python3 "/home/pi2/树莓派心电终端/tools/configure_device_boot.py" status
sudo python3 "/home/pi2/树莓派心电终端/tools/configure_device_boot.py" uninstall
```

撤销只删除本工具增加的启动段与配置，保留其他登录文件修改及原有启动配置。若被管理的段或系统文件已被别人修改，会停止并要求检查，不覆盖。安装与撤销均下次启动生效；确认本次数据保存完成后再重启。若界面异常，可用 SSH 撤销，或切换到其他文字控制台操作。

## 接回树莓派后的验收

- 重启进入全屏待机，无新会话、串口未打开。
- 拔插 USB 设备能更新状态；手动开始后实采波形、质量和分类正常。
- 停止后点数一致，历史记录选中本次会话；再次开始形成独立记录。
- 上传期间波形保持响应；退出与关机等待保存，不丢失本地数据。
- 实际 HDMI 显示、关机和撤销启动配置尚未验证，不能据笔记本测试宣称已完成。
