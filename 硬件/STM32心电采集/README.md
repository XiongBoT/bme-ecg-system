# STM32 心电采集

先查 [共同接口约定](../../docs/接口约定.md)，再结合 [七字节串口协议](Doc/2026-10-27_七字节串口协议.txt)、[PC13/SW2 按键说明](Doc/2026-10-27_PC13按键切换说明.txt) 和 [接线图](Doc/2026-10-14_STM32与AD8232接线图.png) 阅读代码。

`Doc/` 中旧文本协议、旧框图和带日期的验证保留为历史依据；日期文档中的“上位机尚未适配”等描述是当时状态。跨模块结构以[系统架构](../../docs/系统架构.md)和共同接口约定为准，运行版本见[交付状态](../../docs/版本与交付状态.md)。健康助手固定时长由树莓派执行，未改变 STM32 七字节协议。

工具链与编译验收见 [根 README](../../README.md#开发环境)、[贡献指南](../../CONTRIBUTING.md#检查与实物联调)。工程编译输出、个人 Keil 设置不加入 Git。
